# 会議録音メモ

iPhone の Safari で会議の文字起こしをとり、Claude で議事録にまとめて、Word ファイルとして保存・共有する Web アプリです。

## 流れ

1. 会議の情報（会議名・日時・場所・出席者・作成者・専門用語）を入力する
2. 「録音開始」を押す → 会議 → 「停止」を押す（話した内容がその場で文字になります）
3. 「議事録を作成」を押す（Claude が議事録にまとめます）
4. 「Word ファイルを共有」を押す（Word・メール・ファイル・LINE などに送れます）

## 最初の準備

### 1. Claude の API キーを用意する
1. https://console.anthropic.com にサインアップします（claude.ai のアカウントとは別に登録が必要です）。
2. 「Billing」でクレジットを購入します（最低 5 ドルから）。
3. 「API Keys」でキーを作り、アプリの「設定」に貼り付けます。

料金は使った分だけです。目安は 1 時間の会議 1 回で 0.1〜0.3 ドル（約 15〜45 円）です。claude.ai の月額料金とは別にかかります。

### 2. GitHub Pages で公開する
1. このフォルダのファイルを、GitHub の公開リポジトリに置きます。
2. リポジトリの「Settings」→「Pages」で、「Branch」を `main`、フォルダを `/ (root)` にして保存します。
3. 数分すると `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります。

### 3. iPhone のホーム画面に置く
1. Safari で上の URL を開きます。
2. 共有ボタン →「ホーム画面に追加」を選びます。
3. 「Web アプリとして開く」というスイッチが出たら**オフ**にしてから「追加」を押します。
   ホーム画面のアプリとして開くと iPhone の音声認識が動かないことがあるため、Safari で開く形にしておきます。

## 他の人と共有する
URL を送れば、誰でも同じアプリを使えます。API キーは各自の iPhone に保存されるので、**使う人がそれぞれ自分のキーを登録します**。自分のキーを人に渡すのはやめてください。キーを持つ人は誰でも、あなたの残高で Claude を使えてしまいます。

## 注意点
- **録音中は画面をつけたまま、Safari を開いたままにしてください。** 画面が消えたり他のアプリに切り替えたりすると、その間は文字起こしされません。戻ったときは「認識を再開」を押します。
- 文字起こしには iPhone の音声認識（Safari の Web Speech API）を使います。音声データそのものは保存しません。録音を残したい場合は、ボイスメモでも並行して録音してください。
- 音声認識は約 50 秒ごとに区切って自動で再開します。区切りの前後で言葉が一部抜けることがあります。
- ボイスメモで文字起こしした文章を、2 の欄に貼り付けて使うこともできます。
- 入力した内容と議事録は、その iPhone の Safari の中に保存されます。Safari の「履歴と Web サイトデータを消去」を実行すると消えます。
- 文字起こしの文章は、議事録を作るときに Anthropic の API に送られます。社外秘の会議で使ってよいかは、所属先の決まりを確認してください。

## ファイル構成
- `index.html` … 画面
- `app.js` … 録音・Claude 呼び出し・Word 出力の処理
- `vendor.js` … Anthropic SDK（@anthropic-ai/sdk 1.3.0）と docx 9.15.0 を 1 ファイルにまとめたもの
- `manifest.webmanifest`, `icon-*.png` … ホーム画面のアイコン
